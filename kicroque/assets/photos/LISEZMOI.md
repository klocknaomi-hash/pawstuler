# Photos du site

Déposez vos photos dans ce dossier avec **exactement** ces noms (minuscules, sans accents).
Une photo présente remplace automatiquement l'illustration dessinée ; tant qu'elle manque,
l'illustration reste. Aucun code à modifier.

Conseils : compressez vos fichiers (squoosh.app), moins de 300 Ko par photo de cookie,
moins de 600 Ko pour les grandes photos. Autre format pour les cookies (.webp, .png) ?
Changez `extension` dans `js/config.js`.
