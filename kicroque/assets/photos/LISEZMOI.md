# Photos de vos cookies

Déposez vos photos dans ce dossier avec **exactement** ces noms (en minuscules, sans accents).
Une photo présente remplace automatiquement l'illustration dessinée ; tant qu'elle manque,
l'illustration reste. Aucun code à modifier.

Conseils : format carré (1200 × 1200 px), cookie bien centré sur un fond uni, fichier JPG
de moins de 300 Ko (compressez avec squoosh.app). Autre format (.webp, .png) ? Changez
`extension` dans `js/config.js`.
